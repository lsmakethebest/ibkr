使用方法 · 从 IBKR 导出报表
  1. 进入自主查询
    打开 IBKR APP，依次进入「报表和税务」→「活动报表」→「自主查询」。
  2. 使用 AI 配置
    选择「使用 AI 配置」，输入以下内容：

    导出证券转入转出记录需要所有字段、入金出金记录、交易日收盘账户净值（需要包含当前币种）、持仓市值、股息、利息、佣金等费用、所有交易记录，各标的已实现和未实现盈亏

    可长按或选中上方文本复制。计算资金调整收益时，还需导出同期完整出入金明细、本位币现金流水及期初前一条净值；证券转移需提供 Date / Symbol / Direction / Quantity / PositionAmount / CurrencyPrimary。请保留 MTM 或 FIFO 标的盈亏明细，并核对收支汇总，缺失数据不要用 0 代替。USD 净值下，港元入金缺少本位币流水及 FXRateToBase 时，可按同账户入金当日起 7 个自然日内（含第 7 日）的 USD.HKD 买入记录估算；需导出 TradeDate / Buy/Sell / Quantity / TradePrice / Proceeds / CurrencyPrimary / AssetClass，且港元支出合计与入金相符。临近还有其他港元出入金、反向换汇或重复交易时不自动匹配。

  3. 生成并保存
    点击「Generate」，等待生成完成后点击「保存」。
  4. 找到已保存的报表
    返回「活动自主查询」，找到刚保存的报表，点击旁边的「→」下载入口。
  5. 运行并下载
    选择需要的日期范围，点击「运行」，完成后下载 CSV 文件。
  6. 导入并查看收益
    点击本页顶部「上传报表」，选择下载的 CSV，即可查看月度收益、年度收益、历年收益和盈亏分析。

区间盈亏 = 本次净值 − 上次净值 − 现金入金 + 现金出金 − 证券转入市值 + 证券转出市值。日收益率估算 = 区间盈亏 ÷（上次净值 + 现金入金 + 证券转入市值），假设所有流入在区间开始、流出在区间结束。月度、年度及历年收益率 = 期间盈亏金额 ÷（期初净值 + 期间现金入金 + 证券转入市值），展示时乘以 100%。期初净值取首个盈亏区间之前的净值，不使用该区间结束时的净值；出金和证券转出不扣减分母，不按投入天数加权，非年化、非 IBKR 官方收益率。非净值日的现金和证券转移归入下一条净值区间；首条仅作基准，该日流量不重复计入期间本金，净值覆盖范围外的流量不计入。期间本金须为有效正数，否则收益率显示“—”；零资产且无转移的日区间仍不计日收益率。部分报表不代表完整月/年，未提供的转移无法调整；FIFO 标的盈亏不叠加到账户收益。港元入金若采用实际换汇所得美元估算，金额回填到原入金日，换汇本身不再计一次入金，佣金不重复扣除；此金额不是 IBKR 入金日折算值。点击日期查看资金明细。
